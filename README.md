
Jogo 3
Bem-vindo ao Jogo 3! Este é um jogo divertido e desafiador, desenvolvido com JavaScript e a biblioteca p5.js. O jogo é composto por sete fases, cada uma trazendo novas mecânicas e desafios.

Fases do Jogo
Fase 1: Desviar dos Quadrados
Objetivo: Sobreviver por 10 segundos enquanto desvia de quadrados móveis.
Descrição:
Quadrados aparecem na tela e se movem em direções aleatórias.
O jogador precisa se mover para evitar colisões.
Após completar 10 segundos, a próxima fase é desbloqueada.

Fase 2: O Labirinto
Objetivo: Navegar pelo labirinto e chegar ao final.
Descrição:
Blocos dourados espalhados pelo labirinto servem como pontos de "revivência".
Colisões com as paredes fazem o jogador reiniciar no ponto inicial, mas os blocos dourados ajudam a continuar.

Fase 3: Objetos Rotatórios
Objetivo: Pegar o quadrado no centro do cenário e retornar ao ponto inicial.
Descrição:
Objetos rotatórios dificultam a movimentação.
Planejamento e precisão são necessários para evitar colisões enquanto o objetivo é alcançado.

Fase 4: Desafio Rotatório Avançado
Objetivo: Igual à fase 3, mas com maior dificuldade.
Descrição:
A velocidade e a quantidade de objetos rotatórios aumentam, tornando o desafio mais complicado.

Fase 5: O Corredor de Inimigos
Objetivo: Pegar o quadrado no final do corredor e voltar ao ponto inicial.
Descrição:
O corredor está repleto de inimigos em movimento.
O jogador deve evitar os inimigos enquanto completa a missão.

Fase 6: Combinação de Fases 3 e 1
Objetivo: Completar uma combinação dos desafios apresentados nas fases 3 e 1.
Descrição:
O jogador precisa lidar com objetos rotatórios e quadrados móveis ao mesmo tempo.
É uma fase de alta dificuldade e requer concentração máxima.

Fase 7: Inimigos que Sobem e Descem
Objetivo: Sobreviver e completar o desafio enquanto evita inimigos em movimento vertical.
Descrição:
Inimigos se movem continuamente para cima e para baixo.
O jogador deve desviar deles enquanto avança na fase.

Como Jogar
Use o mouse para controlar o jogador.
Complete os objetivos de cada fase para avançar.
Evite colisões e utilize estratégias para superar os desafios.
